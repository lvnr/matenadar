# Samples: pages of real books, rebuilt in Matenadar

Each folder rebuilds a few pages of one of Levon's published books, made
earlier with per-book HTML/CSS (or LaTeX) engines, to see how close
Matenadar's model gets to the same look.

```
samples/<slug>/
  sample.json   which book, which PDF, which original pages map to which rebuilt pages
  make.py       builds doc.json from the book's own sources (text, data, images)
  doc.json      the Matenadar document (generated by make.py; committed)
  README.md     what is rebuilt, how close it is, what differs and why
  GAPS.md       engine features that would close the remaining differences
  book -> the book's project folder (symlink, not committed)
  build/        renders, compare sheets, prepared fonts (not committed)
```

- The asset root is the sample folder, so paths read `book/visuals/...` or
  `build/fonts/...`.
- `python3 scripts/review.py samples/<slug>` builds the document and writes
  `build/compare-NNN.png`, the original page beside the rebuilt one.
- `make.py` must be deterministic and must only read the book. It may prepare
  derived files under `build/`, such as static instances of variable fonts
  made with `uv run --with fonttools`.

| `third-shift-handbook` | 5 | 8–9 | `uv run --with fonttools python3 samples/third-shift-handbook/make.py` |

The scores in each README are the rebuilding agent's, made before the
engine round that followed (2026-10-26). That round fixed what several
samples had worked around: frames aligned to the bottom or middle now
place their text as the book did (I Just Had It p. 5, Reverse Coloring
p. 4 moved 20–24 pt into place), margin notes meet a box at its edge, and
words split into runs keep their letter spacing. The Idioms and Third Shift
generators were updated to drop the workarounds; others still carry a few
that are now unnecessary but harmless.

`python3 scripts/sheet.py` writes `samples/index.html` with every compare
sheet; `--embed out.html` makes one self-contained file.

## Abilities, shown on real books

These samples are not rebuilds: each shows engine abilities on a real book's text and pictures.

| Sample | Shows | Built with |
|---|---|---|
| `picture-book` | the picture-book template: 32 pages, lettered full-bleed story pages, a spread with words over art, typeset front and back matter (Whynarium: How Dinosaurs Worked) | `python3 samples/picture-book/make.py` |
| `nonfiction-figures` | numbered figures, a list of figures, a cross-reference, a full-bleed plate, black ink with the grey filter (The Attention Repair Manual, chapters 1–2) | `python3 samples/nonfiction-figures/make.py` |
| `black-ink` | the black-ink check reporting a colour picture and coloured type, and the grey filter clearing them | `python3 samples/black-ink/make.py` |
| `puzzles` | a maze, a crossword, a Sudoku, a logic grid and a dot-to-dot drawn from data, with their solutions and folios (Christmas Word Search's page) | `python3 samples/puzzles/make.py` |
| `journal` | a month calendar, seven dated pages from one repeated page, dot-grid and graph-paper rulings (The Attention Repair Manual's Leave Note) | `python3 samples/journal/make.py` |
| `paper-craft` | a cube's net with picture faces, cut and fold lines, glue tabs and scissors (I Just Had It) | `python3 samples/paper-craft/make.py` |
| `comic` | comic panels with speech, thought, whisper, shout and caption balloons (I Just Had It) | `python3 samples/comic/make.py` |
| `coloring` | the coloring template: pictures on right-hand pages with blank backs (One Pen: Winter Lights) | `python3 samples/coloring/make.py` |
