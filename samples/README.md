# Samples: pages of real books, rebuilt in Matenadar

Each folder rebuilds a few pages of one of Levon's published books, made
earlier with per-book HTML/CSS (or LaTeX) engines, to see how close
Matenadar's model gets to the same look.

```
samples/<slug>/
  sample.json   which book, which PDF, which original pages map to which rebuilt pages
  make.py       builds doc.json from the book's own sources (text, data, images)
  doc.json      the Matenadar document (generated by make.py; committed)
  README.md     what is rebuilt, how close it is, what differs and why
  GAPS.md       engine features that would close the remaining differences
  book -> the book's project folder (symlink, not committed)
  build/        renders, compare sheets, prepared fonts (not committed)
```

- The asset root is the sample folder, so paths read `book/visuals/...` or
  `build/fonts/...`.
- `python3 scripts/review.py samples/<slug>` builds the document and writes
  `build/compare-NNN.png`, the original page beside the rebuilt one.
- `make.py` must be deterministic and must only read the book. It may prepare
  derived files under `build/`, such as static instances of variable fonts
  made with `uv run --with fonttools`.
